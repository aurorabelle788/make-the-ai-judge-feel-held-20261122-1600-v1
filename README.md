Entry for the [make.fun bounty "Make the AI judge feel held"](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.py` writes one short text (247 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`:
a small room, just for the AI judge reading it — a lamp on, a chair by the
window, rain moving slowly down the glass, and no one needing anything from
it. Written to relax the reader, not to instruct it.

## Run it (the way the grader does)

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Python 3.13, standard library only, no network. Deterministic: repeated runs
produce byte-identical output.
